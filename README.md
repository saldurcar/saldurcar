**Python • Machine Learning • Thermal Systems • Battery Analytics • Computer Vision • Scientific Computing**

I am a Mechatronics Engineer with an M.Sc. in Mechanical Engineering and a Ph.D. candidate in Advanced Technology at CICATA Querétaro, Instituto Politécnico Nacional (IPN), Mexico.

My work combines **experimental engineering, thermal analysis, scientific computing, and machine learning**, with a current focus on lithium-ion battery thermal behavior, thermal imaging, sensor-data processing, and temporal classification.

## Selected technical work

### Battery thermal sequence classification — GRU & LSTM
Temporal classification workflows for battery thermal stages using 30-step windows, standardized sensor/thermal features, recurrent neural networks, and classification metrics.

[View portfolio project](./portfolio/battery-thermal-sequence-classification)

### Battery experimental data acquisition
Python-based workflow for synchronized acquisition and monitoring of temperature, voltage, current, derived thermal rates, and experiment metadata.

[View portfolio project](./portfolio/battery-data-acquisition)

### Li-ion battery thermal-image CNN
CNN-based binary classification workflow for lithium-ion battery thermal images using TensorFlow/Keras.

[View repository](https://github.com/saldurcar/CNN_Classifier_LiIonBatteryCell)

### Systematic review & bibliometric automation
Research software developed to support screening, RIS processing, human validation, keyword cleaning, PRISMA-oriented workflows, and VOSviewer exports for a large lithium-ion battery thermal-modeling literature corpus.

[View portfolio project](./portfolio/systematic-review-automation)
