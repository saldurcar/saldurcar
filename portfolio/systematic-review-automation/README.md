# Systematic Review & Bibliometric Automation

Portfolio summary of research software developed to support a systematic review on **thermal modeling of lithium-ion batteries**.

## Scope of the software

The working application evolved through multiple versions and supports tasks such as:

- RIS ingestion and metadata normalization
- deduplication support
- deterministic screening rules
- Include / Uncertain / Exclude workflows
- human validation and audit fields
- loading previous screening sessions
- keyword and term processing
- bibliometric subsets
- VOSviewer export packages
- PRISMA-oriented counts
- optional supervised ML to prioritize uncertain records
- structured AI-assisted review while preserving human decisions

## Design principle

Automated decisions are treated as **screening aids**, not substitutes for human review. Human decisions remain the authoritative layer.

## Data policy

The literature corpus, copyrighted full texts, API credentials, and review-session data are not published in this portfolio repository.
